# CodeTrack Backend — Live Class

This repository is for learning backend development by building CodeTrack together, one small step at a time.

It starts with documentation only. During the class, we will add the backend code together. Nothing here should be read as a finished application.

## What we will build

CodeTrack will help a learner record study time, keep a streak, and set goals. The backend will eventually provide safe ways to:

- create an account and verify an email address;
- sign in and sign out;
- reset a forgotten password;
- add, view, change, and remove learning logs;
- add, view, change, and remove goals; and
- request the data needed for a dashboard.
